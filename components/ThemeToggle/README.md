# ThemeToggle

One icon button in the main bar that switches between the light and dark themes. It shows the theme the click goes to: a moon in light, a sun in dark. The label changes with the state ("Switch to dark theme", "Switch to light theme").

Follow the system setting until the visitor picks a theme, then keep the pick. Light is the reference theme; many corporate sites show only the light theme, and that is allowed.

**Content:** the current theme. The site sets `data-theme` on the root.
