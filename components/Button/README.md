# Button

- **primary:** `brand` fill, `on-brand` label. One per view: "Request quotation", "Send request".
- **secondary:** `canvas` fill with a 1px `link` ring and `link` label. Parallel actions: "Datasheet", "Request access".
- **tertiary:** text in `link`, underline on hover. Actions in tables and rails: "Download", "Export CSV".

Sizes: `s` 32px (tables, toolbars), `m` 40px (default), `l` 48px. Radius `r-1` (2px). Weight 600.

States: hover, pressed (`brand-pressed`), focus (2px `focus` ring, 2px offset), disabled (`muted` fill, `text-3` label), loading (spinner and a present-tense label).

**Content:** a verb and an object, sentence case: "Request quotation", not "Let's talk".
