# Icon

Lucide icons (lucide.dev), stroke 1.75, round caps and joins, `currentColor`, on a 24px grid. 18px in content, 16px in buttons, links and tables, 20px in the main bar.

Icons are decorative (`aria-hidden`); the text next to them carries the meaning. Use icons less than in Meridian: navigation, downloads, contact data, locks and alerts only.

Common names: search, menu, globe, user, download, lock, file, phone, mail, chevron-right, arrow-right, triangle-alert, check, x, share (export).

**Content:** one Lucide icon name and a size.
