# MasterData

The commercial and regulatory data of a product, in a grid of three columns: order and material number, packaging unit, customs tariff number, export control classification, country of origin, RoHS, REACH, net weight.

Labels 12.5px 600 `text-3`, values 15px. Codes in `data`. Purchasing and customs departments read this block, so keep the field names and order fixed on every product page.

**Content:** the nine fields above.
