# StatusTag

The lifecycle state of a product, as an outlined tag with a text label. 24px high, 1px border in the text color, square corners, 13px 600.

- **In development** (`link`): announced, samples on request.
- **Active** (`success`): in production.
- **Not for new designs** (`warning`): name the replacement.
- **Discontinued** (`danger`): name the last delivery date and the replacement.

Use these exact words. Do not use "Retired", "Legacy" or "Sunset".

**Content:** the state.
