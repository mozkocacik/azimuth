# MegaMenu

Opens under the main bar. A category rail on the left (240px, `panel`), the selected category in the middle with an overview link and grouped link columns, and a side column with the latest change notifications.

The selected category has a `canvas` fill, `link` text and a 3px `brand` line on the left. `shadow-menu`. On phones the menu is a full-screen list in the same order.

**Content:** categories, groups with links, two or three recent notices.
